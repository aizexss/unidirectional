ВОСПРОИЗВОДИМЫЙ КОНЕЧНЫЙ РАСЧЕТ ДЛЯ ПЕРВОЙ СТАТЬИ

Статус: выполненный вычислительный анализ абстрактной модели. Аппаратный
эксперимент AIMI, измерение сети и оценка частоты промышленных отказов отсутствуют.

Запуск: Python 3.10 или новее, только стандартная библиотека.
    python run_model.py
Файлы CSV/JSON пересоздаются в папке скрипта. Случайных чисел нет.
Расчет в этой поставке выполнен на Python 3.12.14.

ОСНОВНОЕ МНОЖЕСТВО
Три неизменяемых исходных поколения имеют уникальные номера 1, 2, 3.
Каждое содержит (0,0) или (1,1); перебираются все восемь исходных историй.
Публичный каталог G = {(0,0),(1,1)} не раскрывает фактическую историю.
Повторение одного значения в разных поколениях допускается.

R0 независимо сохраняет каждое поле вместе с его фактическим происхождением.
Origin каждого поля принадлежит {0,1,2,3}; 0 означает отсутствие поля.
Все 16 комбинаций достижимы при потерях и произвольном порядке доставки.
R1 сохраняет объект целиком: достижимы только (0,0),(1,1),(2,2),(3,3).
Начальное состояние и перезапуск атомарно очищают оба поля. Чтение атомарно.

В основной таблице каждая пара «история — физическое состояние origin» считается
один раз. R0: 8 x 16 = 128 случаев; R1: 8 x 4 = 32 случая. Это не равновероятная
выборка из реального канала. Доли описывают состав конечного множества и не могут
интерпретироваться как вероятность или частота нарушения на оборудовании.

ПРОФИЛИ НАБЛЮДАТЕЛЯ
V: только значения; ни origin, ни свидетельства о группировке не доступны.
G: значения и истинное свидетельство общего origin в R1; для R0 оно неизвестно.
I: значения и origin, доверенно связанные с каждым полем. Подлинность связи
предполагается в модели, криптографической аутентификации скрипт не выполняет.
Для неполного состояния сначала выдается unavailable.

Монитор не получает фактическую исходную историю. Он проверяет существование
объяснения с общим происхождением C и с различным происхождением M относительно
публичного каталога и разрешенных свидетельств. Вердикты: coherent, mixed,
ambiguous, out_of_model, unavailable. Независимый oracle перечисляет все
объяснения с двумя абстрактными origin и всеми векторами каталога и сверяется
с формулой монитора на 225 комбинациях значений и свидетельств.

ДОСТИЖИМОСТЬ И ПЕРЕЗАПУСК
Для R0 перебираются все слова из шести разных сообщений x1,y1,x2,y2,x3,y3,
длина от 0 до 6. Каждое сообщение доставляется ноль или один раз. Для R1
аналогично перебираются три сообщения S1,S2,S3. Порядок произволен, то есть
допускается даже перестановка сообщений одного поля; это консервативная модель,
а не утверждение о транспортном протоколе. Каждое слово проверяется без
перезапуска и с одним атомарным очищением во всех позициях. Повторные состояния
в этих трассах не добавляют веса в основную таблицу. Происхождение не зависит
от чисел, поэтому расписания перебираются один раз; восемь исходных историй
проверяются отдельно на полном множестве достигнутых origin states.
Дубликаты представлены отдельными детерминированными контролями, не полным
перебором всех кратностей. Алгебраический инвариант R1 сохраняется и при
повторной доставке любого целого объекта, независимо от его устаревания.

НЕГАТИВНЫЙ КОНТРОЛЬ
Ложное свидетельство same для (0,0) с origin (1,2) приводит к coherent,
хотя фактическое состояние mixed. Это нарушение предпосылки включения actual
execution в Omega; out_of_model не гарантирует обнаружение ложных метаданных.
Этот контроль не включается в ошибки корректно заданных профилей V/G/I.

изоляции, промышленной надежности и криптографической стойкости. Отношения
мощностей множеств не сопровождаются статистическими доверительными интервалами.
