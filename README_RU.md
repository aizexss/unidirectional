# Проверка согласованности снимков промышленной телеметрии

Код и синтетические данные статьи «Verifying State Snapshot Coherence in Unidirectional Industrial Telemetry». Авторы: Aibar Ibragimov, Leila Rzayeva и Laura Aldasheva. Репозиторий публичный. Материалы доступны для скачивания без запроса доступа; версия для публикации отмечена тегом `article1-submission-20261030`.

Проверенная среда — Python 3.12.14 / Windows. Для точного повтора сохранённых числовых файлов используйте эту версию. Синтаксис программы совместим с Python 3.10+, но совпадение чисел на других версиях не подтверждалось. Достаточно стандартной библиотеки. Команды выполняются из корня репозитория.

## Проверка сохранённых результатов

```sh
python reproduce.py --verify-only
```

Проверяются контрольные суммы файлов, конечная модель, теоретические тождества, все 3 840 000 записей чтения и независимое восстановление событий. Симулятор в этом режиме повторно не запускается.

## Полный повтор расчётов

```sh
python reproduce.py --full
```

Повторно выполняются расчёты, 960 прогонов и bootstrap-анализ. Вычисления идут во временной копии; сохранённые исходные материалы не перезаписываются. Полученные CSV/JSON и распакованный журнал сравниваются с эталоном.

Перед полным пересчётом из временной копии удаляются все 29 старых расчётных файлов. Если программа не создаст хотя бы один из них, проверка завершится ошибкой. Дополнительно каждый из 3 840 000 кортежей чтения сверяется с независимо восстановленным расписанием событий. Проверяются 48 числовых ячеек таблиц и точное совпадение шести изображений с Word-статьёй. Схема соответствия статьи и кода: `docs/TRACEABILITY.md`.

## Что получится

В терминале появляются этапы с номерами и статусами PASS/FAIL. Итоговый код завершения — 0 при успехе и 1 при ошибке. Ошибочные аргументы командной строки дают код 2.

- `reports/RESULTS_RU.md` — читаемый отчёт на русском с основными числами и пояснениями; `reports/RESULTS.md` — английская версия.
- `reports/verification_summary.json` — машиночитаемый результат.
- `reports/*.log` — подробный вывод каждого этапа после локального запуска.

Ожидается: 12 условий, 40 независимых индексов повторения внутри каждого условия, 960 прогонов режимов, 4 000 чтений в каждом прогоне. Для C05 доля смешанных чтений R0 составляет 62,144375% при 100% полноте; у R1 смешанных чтений нет при выполнении контракта атомарности. Повторное использование случайных потоков связывает разные условия; все 480 пар нельзя называть взаимно независимыми.

Все результаты относятся к синтетической модели. Пример с насосом в статье иллюстрирует ложную тревогу и пропущенную неисправность, но не является испытанием оборудования. Состав данных и ограничения подробно приведены в `README.md` и отчёте.

Дополнительно проверяются объём аннотации 250–280 слов, 20 источников в порядке первого цитирования, сведения о трёх авторах и контрольные разряды ORCID. Результат последнего запуска: `reports/verification_summary.json`.

Тесты программы запуска и научных граничных случаев: `python -m unittest discover -s tests -v`.

## Повторное построение рисунков

Для графиков отдельно проверена среда Python 3.12 / Windows. Дополнительные библиотеки нужны только этому этапу:

```sh
python -m pip install -r requirements-figures.txt
python plot_figures.py
python audit_plots.py reports/figures
```

В `reports/figures/` появятся шесть PNG и шесть JPG с разрешением 600 dpi, а также `plot_evidence.json` с использованными числами и хешами CSV. Проверка графиков независимо сверяет 402 точки аналитических кривых, доли по счётчикам прогонов, сводки интервалов и 480 чтений выбранной трассы перезапуска. Пропущенный возраст состояния изображается разрывом, а не нулём. Исходные данные не перезаписываются.

В статье используется Times New Roman. Если он не установлен, можно явно выбрать другой шрифт: `python plot_figures.py --font "DejaVu Serif"`. Числа сохранятся, но внешний вид может отличаться. Шрифты и библиотеки в репозиторий не включены. Для `reproduce.py` по-прежнему достаточно стандартной библиотеки Python.
